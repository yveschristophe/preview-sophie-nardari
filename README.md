# Sophie Nardari — preview

Landing page statique, réalisée à partir des maquettes desktop/mobile fournies.

## Développement

```sh
npm ci
npm run dev
```

La prévisualisation locale est disponible sur `/preview-sophie-nardari/`, comme sur GitHub Pages.

## Vérifications

```sh
npm run lint
npm run typecheck
npm run build
```

Le workflow GitHub Actions publie le contenu de `dist/` sur GitHub Pages après un push sur `main` ou `preview/sophie-nardari`.
